## About Me

I'm interested in how AI systems learn from experience, from long histories of user behavior to interactions with dynamic environments. At Meta, I work on representation learning and scalable recommendation models.


## Research Interests

* ### Representation Learning & Sequential Modeling

Learning user representations from large-scale behavioral sequences, with a focus on long-range dependencies, temporal dynamics, and transferability across recommendation tasks.

* ### Efficient & Scalable Machine Learning

Developing modeling approaches that balance predictive performance with computational efficiency, particularly for large-scale recommendation systems.

* ### LLM Agents & Planning

Exploring how language models can reason, plan, and interact with dynamic environments, with an interest in search-based planning and web agents.

## Selected Research & Projects {#research-projects}

### Monte Carlo Tree Search for LLM-Based Web Agents

*LLM Agents · Tree Search · Planning*

Integrated Monte Carlo Tree Search (MCTS) with the SeeAct web-agent framework to study how search and prompting strategies affect agent planning and execution. Evaluated different configurations on the WebShop benchmark, exploring the tradeoff between exploration and exploitation.

[Code](https://github.com/SyHeee/cs294f24-ai-agents)

### NLP for Document Understanding

*Natural Language Processing · Language Models · Text Classification*

Explored open-source language models for text classification and document understanding, using the MIND news dataset as a reference.

[Code](https://github.com/SyHeee/document-understanding)
