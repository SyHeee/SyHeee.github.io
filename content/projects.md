### Monte Carlo Tree Search for LLM-Based Web Agents

*LLM Agents · Tree Search · Planning*

Explored the integration of Monte Carlo Tree Search (MCTS) with LLM-based web agents to improve planning and decision-making. Studied how prompting strategies interact with tree search and evaluated different configurations on the WebShop benchmark.
